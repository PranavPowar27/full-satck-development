Introduction

This repository contains 12 practical lab exercises completed as part of the Full Stack Development course. The labs span backend development using Node.js and Express, module usage, asynchronous programming, database ORM concepts with Sequelize, frontend development using React, and full-stack integration.

This journal documents:
-  Tasks completed in each lab  
-  Concepts practiced  
-  Tools and libraries used  
-  Outcomes and understanding gained

## Concepts I Found Challenging

### Integration
- Initially struggled with connecting frontend and backend.
- Learned how to use `fetch` and `axios` for API calls.
- Understood how data flows between React and Express.

### File Streaming
- Faced difficulty using Node streams and `.pipe()`.
- Realized streaming is efficient for large files.
- Learned how to avoid memory overload by piping data directly.

### User Queries
- Writing Sequelize queries was tricky at first.
- Understood how to structure CRUD operations.
- Learned to debug and test queries using API routes.

### Context Handling
- Managing state and props across components was confusing.
- Gained clarity on how React context and routing work together.
- Learned to pass and consume data effectively in components.
